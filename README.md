## 🚀 Описание проекта

**MESHKA for Windows** — это графическое приложение для автоматизации производственного тестирования и обслуживания embedded-устройств через UART.

Программа предназначена для работы с несколькими последовательными портами одновременно и предоставляет удобный интерфейс для выполнения производственных операций без использования терминала.

MESHKA for Windows позволяет:

* автоматически обнаруживать UART-устройства;
* выполнять автологин на устройствах;
* запускать производственную прошивку;
* запускать тестовые сценарии;
* проверять аппаратные компоненты устройства;
* работать одновременно с несколькими UART-портами;
* отслеживать состояние подключённых устройств в реальном времени;
* управлять режимами работы станции тестирования.

Проект разработан для использования на производственных линиях, сервисных стендах и лабораториях разработки.

---

## ✨ Возможности

### 🔌 Работа с UART

Программа автоматически обнаруживает подключённые последовательные устройства.

Поддерживаются:

* несколько устройств одновременно;
* параллельная отправка команд;
* автоматическое определение COM-портов;
* мониторинг состояния устройств;
* восстановление соединения при переподключении.
* 

## 🖥 Графический интерфейс

MESHKA for Windows предоставляет удобный графический интерфейс для работы с устройствами.

Возможности интерфейса:

* список подключённых устройств;
* отображение логов выполнения команд;
* управление тестами;
* управление UART-соединениями;
* отображение результатов тестирования.

---

## 🔐 Автоматический вход

По умолчанию используются следующие параметры:

```text
LOGIN     = root
PASSWORD  = root
BAUDRATE  = 1500000
```

## 📦 Установка

1. Скачайте архив последней версии программы.
2. Распакуйте архив в удобную директорию.
3. Запустите:

```text
Meshka.exe
```

Установка дополнительных компонентов не требуется.

## 🔧 Настройка UART

По умолчанию программа автоматически обнаруживает все доступные COM-порты.

Поддерживаются:

```text
COM1
COM2
COM3
...
```

Пользователь может выбрать необходимые устройства непосредственно в интерфейсе программы.

---

## 🔄 Восстановление соединения

Поддерживается:

* переподключение устройств;
* повторное обнаружение COM-портов;
* восстановление соединения без перезапуска программы.

---

## ⚡ Параллельная работа

MESHKA for Windows поддерживает одновременную работу с несколькими устройствами.

```text
COM3 ──┐
COM4 ──┼── MESHKA
COM5 ──┘
```

Это позволяет значительно ускорить процесс тестирования и прошивки устройств.
